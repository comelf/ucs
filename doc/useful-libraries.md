# Useful Libraries

## Java

| Library | Description | Link |
|---------|-------------|------|
| fastutil | Java Collections Framework를 확장하여 type-specific maps, sets, lists, queues 제공. 기본형(primitive) 컬렉션으로 오토박싱 없이 메모리와 성능 최적화. | https://github.com/vigna/fastutil |
| picocli | CLI 앱 구축 프레임워크. 색상, 자동완성, 서브커맨드, GraalVM 네이티브 이미지 지원. 단일 소스 파일로 의존성 없이 포함 가능. | https://github.com/remkop/picocli |
| JavaCC | Java용 파서 생성기. 문법 명세를 읽어 top-down recursive descent 파서를 생성. JJTree(구문 트리), JJDoc(문법 문서화) 등 보조 도구 포함. | https://javacc.github.io/javacc/ |
| Apache DataSketches | 대규모 데이터 스트리밍 분석용 확률적 자료구조 라이브러리. cardinality 추정, quantile, frequency, 집합 연산 등을 수학적 오차 보장과 함께 근사 계산. Java/C++/Python/Rust 지원. | https://datasketches.apache.org/ |
